# GG Lua Scripts 历史归档

GitHub: https://github.com/h5box/gg-lua-scripts

## 简要说明：
- 这是 2020-2024 年 GG 脚本库源码和脚本集合的历史归档。
- 原域名 `gg.kuaibiji.*` 已不可用，代码中的线上地址仅作历史记录。
- 所有脚本来自网友上传，仅供学习，本站不对脚本负责。
- 项目包含旧 PHP 站点入口、旧 Lua 云脚本接口和按游戏分类的脚本归档。

------------

## 关于旧在线运行脚本
### 1.[GG脚本库]在线运行.lua
 - 这是旧时代的在线运行脚本，早已不可用。
 - 该文件当时做过加密/编译处理，不作为当前可运行入口。

- `conn.php` 为数据库连接配置，占位内容不会包含真实凭据。
- `.log/`、`app/cache/`、证书验证文件和备份压缩包不纳入版本库。
