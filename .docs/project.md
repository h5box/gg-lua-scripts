# 项目概览
本项目是 2020 年 GG 脚本库的历史归档，主要由旧 PHP 页面和大量
GameGuardian Lua 脚本组成。原域名 `gg.kuaibiji.info` 已不可用，
代码中的线上地址仅保留为历史引用。

# 关键入口
- `index.php`：旧根页面，曾处理上传表单、Lua 启动片段和默认 404。
- `api.php`：旧接口，曾按目录或文件标识查询脚本数据。
- `download.php`：旧接口，曾按文件标识下载脚本并累计下载次数。
- `lua/main.php`：旧云脚本接口，曾生成 GameGuardian 端主菜单 Lua。
- `[GG脚本库]在线运行.lua`：旧在线运行脚本，已不可用且为加密/编译内容。
- `app/`：PHP 文件浏览器应用，用于目录浏览展示。

# 目录说明
- `lua/`：云端脚本接口、用户配置、收藏、评论、运行脚本等模块。
- `app/src`、`app/views`、`app/config`：文件浏览器源码、模板和配置。
- `app/vendor`：第三方 PHP 依赖；当前无 Composer 清单，暂保留在仓库中。
- 中文游戏目录：按游戏名称归档的 `.lua` 脚本集合。

# 历史归档说明
- 本仓库用于保存旧源码和脚本归档，不代表线上服务仍可运行。
- `conn.php` 是数据库连接占位，公开仓库不得写入真实账号密码。
- `.log/`、`app/cache/`、ACME challenge、备份压缩包属于运行产物。
- 仓库未声明开源许可证；需要授权复用时应由维护者明确选择许可证。
